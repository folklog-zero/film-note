# フィルム撮影手帳（GitHub Pages版）

フィルムの装填とコマの記録、露出計（天気・ライブ測光・写真・EV入力）、被写界深度、日の出・日の入りとゴールデンアワー、チェックリストを1ページにまとめたWebアプリです。記録は使っている端末のブラウザの中だけに保存され、どこにも送信されません。

## 公開のしかた

1. GitHubで新しいリポジトリを作ります（名前の例：`film-note`）。無料プランでGitHub Pagesを使えるのは公開リポジトリだけなので、「Public」にします。コードは誰でも見られる状態になりますが、撮影の記録は各端末の中にしか保存されないため、リポジトリに個人の記録は入りません。
2. リポジトリの画面で「Add file」→「Upload files」を選び、このフォルダのファイルを全部アップロードします（`index.html`、`sw.js`、`manifest.webmanifest`、アイコン3つ、`README.md`）。`.nojekyll` は表示されなければ無くても動きます。
3. 「Settings」→「Pages」を開き、「Build and deployment」の Source を「Deploy from a branch」、Branch を「main」と「/(root)」にして Save します。
4. 数分後、`https://（ユーザー名）.github.io/（リポジトリ名）/` で開けるようになります。

## スマホで使う

- **Android（Xiaomi など、Chrome）**：ページを開き、右上のメニュー（︙）から「ホーム画面に追加」または「アプリをインストール」を選びます。一度開いておけば、電波のない場所でも起動できます。
- **iPhone（Safari）**：共有ボタンから「ホーム画面に追加」を選び、ホーム画面から使ってください。Safariで開いたままだと、しばらく開かないうちに記録が消えることがあります。
- カメラと位置情報は、初めて使うときに許可を求められます。

## ライブ測光の初回設定

1. 「露出」→「ライブ」→「カメラを起動」。
2. 「この端末の対応状況」を開いて、測り方を確認します。
   - **手動露出**：いちばん正確な方式です。アプリがカメラの露出時間と感度を決めて、その値から明るさを計算します。
   - **自動露出の報告値**：端末が報告する値を使います。値がずっと同じままなら、正しく測れていません。
   - **明暗差だけ**：このブラウザはカメラの露出の値を教えてくれないため、明るさの絶対値は測れません。「状況」か「写真」を使ってください。
3. 「スマホのレンズのF値」にメインカメラのF値を入れます（Xiaomi 17T は f/1.7 なので初期値は 1.7）。
4. 「補正」で合わせます。晴れた日中の順光の景色が EV15 前後になるか、デジカメの露出計と同じ場面で比べてください。スマホの画像処理によってずれるので、この調整は一度やっておくのが前提です。
5. 背面に複数のカメラがある機種で超広角などが選ばれてしまったら、「使うカメラ」でメインカメラを選び直します。

うまく測れないときは「対応状況をコピー」で出てくる文字を Claude に貼ってもらえれば、原因を調べられます。

## ほかの端末への引っ越し

「履歴・設定」→「ファイルに書き出す」で保存したファイルを、移す先の端末で「ファイルを読み込む」→「今の記録に足す」（または「置き換える」）。自動の同期はありません。

## 更新するとき

`index.html` などを上書きでアップロードします。端末に古い版の控えが残っているので、反映されるのは次の次に開いたときです。すぐに反映させたいときは、`sw.js` の `film-note-v1` を `film-note-v2` のように書き換えてから一緒にアップロードしてください。
